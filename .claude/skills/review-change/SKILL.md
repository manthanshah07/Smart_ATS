# Review Change
Read-only review; do not edit or commit.

Check: task scope and unrelated changes; correctness/edge cases/transactions/contracts/status transitions; auth, role and object ownership; upload validation; secret handling; privacy of candidate/resume data; meaningful positive/negative/boundary tests; accurate docs and limitations; maintainability; unsupported claims about hiring fairness/AI accuracy. Report severity and file/line evidence, plus checks still needed. For audit-only tasks verify no application source files changed.
